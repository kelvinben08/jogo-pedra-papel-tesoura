# Jogo Pedra, Papel e Tesoura
- Programa em Python que permite ao usuário jogar Pedra, Papel e Tesoura contra o computador.

---

### Funcionalidades
- O usuário escolhe entre pedra, papel ou tesoura
- O computador faz uma escolha aleatória
- O programa compara as escolhas
- O resultado da partida é exibido

---

### Como executar

```bash
python main.py
```

---

### Exemplo de uso
```
Escolha: pedra, papel ou tesoura? papel
O computador escolheu: Pedra
Você venceu!
```

---

### Tecnologias utilizadas
- Python 3
